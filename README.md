## How to run

**Option 1: in your browser (easiest)**
Click a **▶ Play / Open** link above. The projects are hosted on GitHub Pages and run straight away on desktop or mobile.

**Option 2: on your own computer**
1. Open the project's repo and click **Code → Download ZIP**, or clone it:
   ```bash
   git clone https://github.com/niteshsrivastava484/snake-game.git
   ```
2. Unzip it if you downloaded the ZIP.
3. Double-click `index.html` to open it in any modern browser (Chrome, Edge, Firefox, Safari).

You don't need a server, build step, or internet connection after downloading.
